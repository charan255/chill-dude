# 🌿 Chill Dude  
> Smart Focus & Relaxation System for Students  

Chill Dude is a productivity + emotional balance platform designed to help students manage academics while preventing burnout.

It combines:
- 📚 Academic tracking  
- 🎯 Focus optimization  
- 🌿 Relaxation tools  
- 📊 Mood analytics  

---

## 🚀 Features

### 🎯 Focus Mode
- Adaptive Pomodoro timer  
- Priority task suggestions  
- Urgency tracking  
- Weekly productivity insights  
- Task completion persistence  

---

### 📚 Academic Profile
- Subject management  
- Syllabus chapter tracking  
- Assignment manager  
- Timetable scheduling  
- Progress visualization  

---

### 🌿 Relax Mode
- Mood-based smart suggestions  
- Micro break timers  
- Soundscapes (YouTube embedded ambience)  
- Quick micro-games  
- Relax XP & streak system  

---

### 🧠 Mood Analysis
- Camera-based scan simulation  
- Dynamic mood selection  
- Dominant mood calculation  
- Confidence scoring  
- Visual mood spectrum  

---

## 🛠 Tech Stack

### Frontend
- React (Vite)  
- Tailwind CSS  
- Lucide Icons  

### Backend
- Node.js  
- Express.js  
- Prisma ORM  
- PostgreSQL  

### Database Hosting
- Supabase (Free Tier compatible)  

---

## 🏗 Architecture

Frontend (React)  
↓  
REST API (Express)  
↓  
Prisma ORM  
↓  
PostgreSQL Database  

- Academic data feeds Focus page  
- Focus + Relax systems interconnected  
- State-driven UI  
- Persistent storage (no mock data)
